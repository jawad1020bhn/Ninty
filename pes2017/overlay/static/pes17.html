3b. Tables measured from your before/after saves

Each pair op writes exactly the bytes PES 2017 itself wrote for one change (formation, tactics, XI, budget). Offsets are fixed to this save and the before-state is checked first. The custom ops let you write your own values into those same measured tables.

Reads club crests offline from the patch folder: loose PNG/JPG/DDS files or flag/e_<id>_r.dds entries inside CPK archives. Nothing is ever written into the game folder.
