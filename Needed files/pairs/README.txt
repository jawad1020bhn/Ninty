PES 2017 BEFORE / AFTER SAVE PAIRS
=================================
One pair = ONE single change inside Master League.
The original ML00000011 already in "Needed files" is the BEFORE for every pair.

For EVERY pair:
  1. Put the original ML00000011 back in the PES 2017 save folder.
  2. Start PES 2017, make ONE change, Save to slot ML00000011, quit the game.
  3. Copy the new ML00000011 into the *_after folder.
  4. Copy the original ML00000011 into the *_before folder.
  5. Fill in _WHAT_I_CHANGED.txt

Never change two things in one pair. Never advance time in the same pair.
Never modify EDIT00000000. Close the game before copying files.

Pairs and the ONE change for each:
  formation         Formation 4-4-2 to 4-3-3
  xi                Swap ONE player in the starting XI
  tactics           Change ONE tactical option
  contract          Renew ONE contract OR change ONE wage
  budget            Change the transfer budget OR salary budget
  my_offer          Send ONE transfer offer from Birmingham City FC
  forced_transfer   Complete ONE incoming transfer
  loan              ONE loan in or out
  youth             Promote ONE youth player
  training          ONE training / development change
  points            Play ONE match OR advance ONE day (do this LAST)

Priority if you only want a few: formation, xi, contract, budget.
Already working without pairs: shirt numbers and AI-club negotiations.
